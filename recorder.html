Connecting to meeting…

Keep this recorder tab open. You can return to Meet while it works.

Start the local service first (see README), then paste its access token below. Audio goes only to the service at 127.0.0.1:8765 on this computer. The token is kept in memory for this tab only.

Please let everyone know before you start transcribing.

Microphone input is mixed with meeting audio. This mode cannot identify speakers. Meet’s mute button does not mute this separate microphone capture; stop transcription to stop capturing it.
